# Siemens OZW672 Unofficial — Enhanced Fork

**0.4.0-beta2**

An unofficial enhanced fork of the [original Siemens OZW672 integration by
John Ahern Infotrack](https://github.com/johnaherninfotrack/homeassistant_custom_siemensozw672).

After installation, restart Home Assistant and add **Siemens OZW672
(Unofficial)** through **Settings → Devices & services**. Configure the gateway
host and credentials, then open **Configure → Datapoint Browser** to add only
the datapoints you need. Normal polling reads only those selected datapoints.

This is a public beta. See the [README](README.md) for setup, limitations,
licensing, and attribution.
